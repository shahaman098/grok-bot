# BumpIn × Love at First Bot — Track 2

BumpIn helps attendees find a useful collaborator in the room. They volunteer what they offer and need, receive a recommendation with profile evidence, and mutually accept an introduction. Both receive an opener and a suggested ten-minute task.

Love at First Bot adds a playful host and optional, personally approved jokes. Both people separately approve the exact content before it can appear on a projected match reveal. Either can revoke stage sharing.

**Implemented:** Next.js/TypeScript, Supabase profiles and protected connection RPCs, explicit consent, rules-based matching, mobile attendee views, venue map and stage reveal. MIT licensed.

**Boundaries:** no verified Grok Bot integration, no external AI processing, no LinkedIn scraping, no live Luma ingestion, no precise GPS. The map uses venue-anchored markers. Profiles are self-declared. Acceptance is not proof that collaboration happened.

# Rehearsal checklist

- Apply SQL migrations in filename order, including venue protection and Love at First Bot. Check configured Supabase auth and the guest-session database connection.
- Use two physical phones with independent browser sessions on the same HTTPS deployment. Local browser preview syncs only tabs within one browser.
- Join the same event with visibility explicitly selected. Add complementary offers and needs.
- Find a collaborator; verify evidence, self-exclusion and no irrelevant matches.
- Request from A, accept on B, and verify confirmed acceptance and next-step suggestions on both.
- Select an optional joke, review exact stage content, approve separately on each phone, then open the stage URL on a laptop.
- Confirm that neither partial approval nor a guessed stage URL reveals any attendee details.
- Reveal; revoke on B; confirm the stage clears after the next permission check. Repeat hide/leave to verify publication is unavailable.
- Test a declined request, offline error and retry without duplicate or false acceptance.
- Ask a consenting community lead and the participants whether the introduction helps. Record feedback truthfully.
- Verify the public repository and licence; rehearse within three minutes. Clearly label synthetic profiles and backup recordings.

# 3-minute live demo script

**Production:** https://bumpin-silk.vercel.app  
**Join:** https://bumpin-silk.vercel.app/e/grok-bot-london  
**QR page:** https://bumpin-silk.vercel.app/qr

1. **Hook (20s):** “At a crowded hackathon, the right collaborator can be meters away but invisible.”
2. **Phone A (30s):** Scan QR → join → name, avatar, optional LinkedIn → opt into map.
3. **Phone B (25s):** Join → show second avatar appearing on A.
4. **Map (25s):** Zoom, tap avatar, Vaul sheet → LinkedIn.
5. **Event (20s):** Tap venue pin → Luma link.
6. **Matching (40s):** “Find people to meet” → suggested query → show match + reason + source badge.
7. **Close (20s):** Community infrastructure, QR for any event, rules-based introductions today, with an optional Grok adapter pending verified integration.

Rehearse twice on mobile data before code freeze. See `REHEARSAL-CHECKLIST.md`.

## Source notes

The overview and tracks 2–5 are unchanged copies of the five pasted text attachments. Track 1 and the wildcard were saved from the chat message with Markdown headings; the repeated wildcard passage and modal close labels were omitted.

These files preserve the supplied briefs. Claims such as API availability, rates and “tested 22 Oct” originate in that material and have not been independently verified here. The referenced Data starter kit itself was not supplied.

The overview refers to six shared judging criteria but the supplied text lists five: technical execution, use of community context, better than what leads use today, real-world usefulness, and demo quality.
